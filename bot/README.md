# 🚀 SkillRack Automation using Selenium (Microsoft Edge)

> ⚠️ Educational Purpose Only  
> This project is created to learn Selenium automation.  
> Do NOT misuse this project or violate SkillRack terms.

## 📌 Project Overview

This project automates:
- Login to SkillRack
- Navigation through Code Tutor
- Captcha solving using EasyOCR
- Fetching solution code
- Human-like typing into the editor
- Running and submitting solutions

### Software
- Windows OS
- Python 3.10+
- Microsoft Edge Browser
- VS Code
